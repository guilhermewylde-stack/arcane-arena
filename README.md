# Arcane Arena

Arena brawler 3D de magos para PC, feito em Godot 4.6. Veja `docs/PRD.md` para a visão e `docs/issues/README.md` para o progresso.

Para jogar durante o desenvolvimento: instale o [Godot 4.6](https://godotengine.org/download), abra `project.godot` e aperte F5.

Para jogar sem o editor: baixe o `ArcaneArena.exe` do último build (aba Actions → artefato `ArcaneArena-windows`) ou de uma release (tags `v*`).

Visão de cima: botão direito move · Q W E R D F lançam magias no cursor. Scroll aproxima até a 3ª pessoa: W A S D movem · mouse mira · 1–6 escolhem a magia · clique esquerdo lança. Esc abre o menu (partida, opções de vídeo e teclas). F11 tela cheia.

Opções de janela (tela cheia, resolução, vsync) ficam em `%APPDATA%\Godot\app_userdata\Arcane Arena\settings.cfg` (também editáveis no menu Opções).
